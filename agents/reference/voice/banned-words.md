# Banned words and their plain replacements

Curated from the GOV.UK style guide A-Z, trimmed to what agents write.
Replace the word on the left, or keep it when it is the exact technical term
and say why in one clause. Add a word only after seeing it in real output.

| Avoid | Use |
|---|---|
| additionally | also |
| advance (verb; "in advance" is fine) | improve, or the specific change |
| amend, amended (when "change" fits; keep legal filing terms) | change, update |
| collaborate | work with |
| combat | stop, fix |
| commence | start |
| confirm (a fact you checked) | check |
| deprecated (outside an API, flag, or tool status) | old |
| display, exhibit, present (verb, when it means show) | show |
| eliminate | remove, delete |
| ensure | make sure |
| initiate, launch (non-technical) | start |
| locate | find |
| modify, alter | change |
| necessitate | need |
| require (when "need" fits; keep spec RFC-2119 "MUST/REQUIRED") | need |
| terminate, halt, cease (non-technical) | stop |
| validate, verify (when it means a manual look, not a validator run) | check |
| comprehensive | complete, full |
| deliver | make, create, provide |
| deploy (non-technical) | use, put in place |
| dialogue | talk, discussion |
| empower | let, allow |
| endeavour | try |
| facilitate | run, help, or the specific action |
| foster | encourage, help |
| going forward | from now on |
| impact (verb) | affect, change |
| in order to | to |
| incentivise | encourage |
| key (adjective) | important, or drop it |
| leverage | use |
| liaise | work with |
| moreover | also, or drop it |
| numerous | many |
| overarching | main, or drop it |
| prior to | before |
| progress (verb) | work on |
| purchase | buy |
| robust | well tested, or the specific property |
| streamline | simplify |
| subsequently | then, later |
| supersede, superseded by | replace, replaced by |
| sufficient | enough |
| tackle | solve, deal with |
| transform | say the actual change |
| utilise, utilize | use |
| whilst | while |

Turkish-reader note: prefer words with one meaning. "Address" (verb),
"handle", and "manage" hide the action; name the action instead.
