# Nix, NixOS, flakes, and Home Manager

- Before you download a binary, patch a package, or add a workaround on a Nix host, search nixpkgs packages and options (search.nixos.org) for one that already solves it. For NixOS, Nix, flakes, or Home Manager behavior, check the current [NixOS Wiki: Flakes](https://wiki.nixos.org/wiki/Flakes) and the relevant official documentation before deciding; use the repository and upstream source to confirm version-specific details.
- For Nix validation, use a JSON gate: `nix eval --json --no-write-lock-file <flake-ref>` prints booleans and structured values, while `--raw` is for strings; evaluate an attrset and pipe it to `jq -c 'has("<key>")'` when checking key existence. Keep Nix expressions inside `--expr` or `--apply`; a bare expression after the flake reference is an extra CLI argument. Treat `nix flake check --no-build` as evaluation evidence, not activation or hardware evidence. Validate only the host in scope, on the host the agent runs on.
